# v0.4.3

## What's New

Selectively adopts reliability guidance from oh-my-opencode-slim v2.2.18. Preset IDs, role names, and model/effort mappings remain unchanged.

## Fixes & Reliability

- Orchestrator and the managed orchestration Skill reconcile actual artifacts and validation evidence when a specialist returns an empty or unusable reply. Sufficient evidence permits completion without repeating work; missing evidence keeps the lane unresolved and calls for a bounded follow-up.
- Repository CI now checks real package installation on pull requests using the same smoke command as release validation. This checks packaged agents and Skills, not live Codex execution or model access.

## Installation / Upgrade

Download `slim-agents-for-codex-0.4.3.tgz` from this release, then run:

```bash
npm install --global ./slim-agents-for-codex-0.4.3.tgz
slim-agents-codex switch-preset --preset openai-5.6 --scope global
```

For a first installation, use `install` instead of `switch-preset`. Use `openai-5.5` to retain that model generation. Start a new Codex task after updating agents and Skills.
