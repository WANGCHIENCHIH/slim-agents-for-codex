# v0.4.0

v0.4.0 makes preset identities stable across same-generation updates and strengthens installation, switching, validation, and recovery.

## What's New

- **Stable model-generation presets.** The supported preset IDs are now `openai-5.5` and `openai-5.6`. `latest` and `recommended` resolve to `openai-5.6`.
- **One Current Role Contract.** Both supported presets generate the same seven roles; only their model and reasoning-effort mappings differ.
- **Generated Root profiles.** Each preset includes `orchestrator.config.toml` and `council.config.toml` for starting Codex directly in the corresponding Root workflow.
- **Package-aware snapshots.** Generated manifests identify both the Package Version and Preset ID so an installed configuration can be traced to its exact release boundary.

## Breaking Changes & Migration

Revision-suffixed preset IDs are retired. `openai-5.5.1` and `openai-5.6.1` through `openai-5.6.4` now fail before writing and direct you to the matching generation ID. There is no silent alias or model fallback.

After installing the v0.4.0 package, migrate an existing global installation with:

```bash
slim-agents-codex switch-preset --preset openai-5.6 --scope global
```

Use `--scope project` instead for a project-scoped installation. Use the historical Package Version or Git tag when you need the exact output of a retired preset.

## Fixes & Reliability

- `install` and `switch-preset` detect managed-state changes after preview instead of overwriting newer changes.
- Post-install validation checks the managed role set, role `config_file` targets, parsed TOML semantics, and both packaged Slim Skills.
- Failed writes restore the managed state they touched and report incomplete rollback plus retained recovery artifacts when full restoration is impossible.
- Switching removes inactive managed roles such as Observer while preserving unrelated custom agents and Skills.
- Snapshot checks now reject missing, extra, or stale generated preset artifacts.

## Installation / Upgrade

Download `slim-agents-for-codex-0.4.0.tgz` and its `.sha256` file from this Release.

For a new global installation:

```bash
npm install --global ./slim-agents-for-codex-0.4.0.tgz
slim-agents-codex list-presets
slim-agents-codex install --preset openai-5.6 --scope global
```

For an existing global installation:

```bash
npm install --global ./slim-agents-for-codex-0.4.0.tgz
slim-agents-codex switch-preset --preset openai-5.6 --scope global
```

The package is distributed through GitHub and is not published to the npm registry. See `README.md` for project-scoped and manual installation instructions. Start a new Codex task after changing agent configuration.
