# v0.4.5

## What's New

Adds the `openai-6` preset and makes it the `latest` and `recommended` default. GPT-6 maps prior Sol roles to `gpt-6-astra`, Terra to `gpt-6-sol`, and Luna to `gpt-6-luna`, preserving reasoning effort and role behavior. Explicit `openai-5.5` and `openai-5.6` mappings remain unchanged.

Updates the reviewed provenance to oh-my-opencode-slim v2.2.22 for all seven roles.

## Breaking Changes & Migration

This release removes the generated `council.config.toml` and `orchestrator.config.toml` Root profiles. Council and Orchestrator remain available as child agents coordinated by a general Root through `$slim-goal-loop`.

If you manually copied either generated Root profile into a Codex home, remove only the copied profile files. Keep the child-agent TOMLs under `agents/` and their existing entries in `config.toml`; `$slim-goal-loop` still uses those agents.

To continue with a new goal, open a Codex task using a general Root and paste this into the Codex message input. This is not a shell command:

```text
$slim-goal-loop
Goal: [the outcome you want]
Acceptance criteria:
1. [a result that can be checked]
Scope constraints: [optional limits or approvals]
```

## Fixes & Reliability

- Generated Orchestrator and Council prompts, plus their managed Skills, omit child `model` and `reasoning_effort` by default.
- Explicit overrides require a Root-relayed explicit user request or a higher-priority host instruction, plus confirmation that both the host tool and selected role support the exact values. Unsupported or unverifiable requests are reported without guessing, fallback, role changes, or lifecycle duplication.
- Reusing an output directory with `convert` removes leftover `council.config.toml` and `orchestrator.config.toml` profiles; `convert --check` rejects either leftover file without modifying the directory.
- The public CLI contract tests cover all three generated presets and both coordinator Skills, including GPT-6 generation, default installation, and switching. Live Codex model entitlement and override behavior remain unverified.

## Installation / Upgrade

Download [slim-agents-for-codex-0.4.5.tgz](https://github.com/WANGCHIENCHIH/slim-agents-for-codex/releases/download/v0.4.5/slim-agents-for-codex-0.4.5.tgz) from this release, then run:

```bash
npm install --global ./slim-agents-for-codex-0.4.5.tgz
slim-agents-codex switch-preset --preset openai-6 --scope global
```

For a first installation, use `install` instead of `switch-preset`. Use `openai-5.5` or `openai-5.6` to retain that model generation. Start a new Codex task after updating agents and Skills.
